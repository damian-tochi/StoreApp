## Overview

StoreApp is an Android shopping application built to explore modern mobile commerce experiences using clean architecture principles and intuitive UI design.

The project focuses on:

- Product discovery experiences
- Scalable Android architecture
- Smooth UI interactions
- Reusable Compose components
- Responsive shopping flows
- Clean state management

---

## Features

- Product listing interface
- Product detail screens
- Wishlist / favorites UI
- Reusable UI components
- Smooth animations & transitions
- Responsive mobile layouts
- Modern UI design system

---

## Architecture

StoreApp follows modern Android development practices with emphasis on:

- Clean architecture principles
- Separation of concerns
- Reusable composable UI systems
- Scalable state management
- Maintainable code structure

---

## Goal

The goal of this project is to experiment with modern e-commerce UI systems and build polished shopping experiences with strong emphasis on performance, scalability, and usability.
